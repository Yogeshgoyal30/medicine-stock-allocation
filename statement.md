# Medicine Stock Allocation and Pharmacy Management System

## Problem Statement

Managing medicines manually can become difficult when there are many patients and different medicines in stock. It can be easy to lose track of available quantities or previous medicine issues.

The purpose of this project is to create a simple Python-based pharmacy management system that keeps track of available medicines and helps allocate medicines to patients. The system updates the stock after a medicine is issued and also maintains a history of the medicines given to each patient.

## Scope of the Project

The project focuses on basic medicine stock management and allocation. A patient can enter their patient ID, view available medicines, request a medicine, check the medicines already received, and view their medicine history.

The system stores medicine and transaction information in text files so that the data remains available even after the program is closed.

## Target Users

The main target users are:

* Hospital pharmacy staff
* Patients using the pharmacy system
* Students learning basic inventory and file-based management systems

## High-Level Features

* Patient ID-based access
* Display of available medicines
* Medicine request and allocation
* Automatic stock update after allocation
* Out-of-stock checking
* Quantity validation
* Patient medicine history
* Record of medicines issued
* File-based data storage
* Simple command-line interface

## Project Objective

The main objective of this project is to develop a simple and easy-to-understand system that demonstrates how Python programming can be used to solve a real-world medicine inventory and allocation problem.
